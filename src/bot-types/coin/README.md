## Managed hosting

This bot type is launched through the manager. Each hosted bot gets an isolated SQLite database and receives its Discord token and owner ID from the manager; do not add credentials to this source tree.

The optional HTTP API is disabled unless both `COIN_API_PORT_BASE` and the `COIN_API_KEY` secret are configured. Each Coin instance receives the base port plus its stable position among hosted Coin bots. API calls must send the key in the `x-api-key` header.
